# Source grounding summary

## S1 - Interagency Integrated Triage Tool (IITT) overview

- Authority: World Health Organization
- URL: https://www.who.int/tools/triage
- Verified: 2026-09-28
- Support: IITT is facility-based triage; red=high acuity/immediate, yellow=moderate/soon, green=low/can wait.
- Role: Scope, terminology, claim boundary

## S2 - Interagency Integrated Triage Tool: Age >= 12

- Authority: WHO / ICRC / MSF
- URL: https://apps.who.int/gb/MSPI/pdf_files/2022/10/Item1_27-10.pdf
- Verified: 2026-09-28
- Support: RED criteria include Unresponsive; Respiratory distress or central cyanosis; Heavy bleeding; Active convulsions; High-risk trauma.
- Role: Primary source for all five model features and the reduced high-acuity mapping

## S3 - Facility-Based Mass Casualty Triage - Guidance Note (MC-IITT)

- Authority: World Health Organization
- URL: https://cdn.who.int/media/docs/default-source/integrated-health-services-(ihs)/csy/mcm-triage_guidance-note.pdf?sfvrsn=d20449f5_2
- Verified: 2026-09-28
- Support: Non-walking/walking is an initial mass-casualty triage dimension; Red additionally requires critical signs.
- Role: Supports mobility as contextual app data; mobility is excluded from the binary LR target/model in v5

## S4 - START Adult Triage Algorithm

- Authority: U.S. HHS CHEMM
- URL: https://chemm.hhs.gov/incident-primer/triage/start-triage
- Verified: 2026-09-28
- Support: Uses ability to walk plus breathing, respiratory rate, perfusion and mental status.
- Role: Supporting source for mobility only

## S5 - SALT Mass Casualty Triage Algorithm

- Authority: U.S. HHS CHEMM
- URL: https://www.chemm.hhs.gov/incident-primer/triage/salt-triage
- Verified: 2026-09-28
- Support: Uses movement in global sorting and evaluates breathing, respiratory distress, hemorrhage, perfusion and mental status.
- Role: Supporting source; not implemented as the project label rule

## S6 - Validation of the Interagency Integrated Triage Tool in Papua New Guinea

- Authority: The Lancet Regional Health - Western Pacific / PubMed
- URL: https://pubmed.ncbi.nlm.nih.gov/34527985/
- Verified: 2026-09-28
- Support: Clinical validation study of IITT in an emergency-department setting.
- Role: Related validation literature only; does not validate this synthetic rescue-report surrogate

## S7 - Interagency Integrated Triage: Reference card
