# Fonts from the CTU template

The template explicitly sets K2D for title styles and Readex Pro for body/subtitle styles. Barlow appears in supplementary template styles. These explicit layout/master settings override the generic Calibri theme fallback.

Sources: the official [Google Fonts repository](https://github.com/google/fonts), paths `ofl/k2d`, `ofl/readexpro` and `ofl/barlow`. Each family retains its supplied `OFL.txt`.

Install the Regular/Bold TTF files for K2D, Readex Pro and Barlow to reproduce rendering. The original Readex Pro variable font is also retained; the static Regular/Bold instances fix `HEXP=0` and weights 400/700 for compatibility. Do not install the variable and static versions simultaneously if your operating system reports a duplicate family.
