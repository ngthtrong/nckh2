## 2. Dataset Preparation Scope

### Image branch

The notebook now supports the exact workflow requested in the prompt:

| Requirement | Implementation |
|---|---|
| FloodNet remap | 10 original classes are remapped into `no_flood`, `low_flood`, `high_flood` |
| CrisisMMD remap | Flood-related events are mapped from `damage_severity` into the same 3-class schema |
| Kaggle supplements | Ground-level flood datasets are supported as additional phone-like images |
| Vietnam-specific subset | Dedicated crawling/collection block for Central Vietnam flood imagery |
| Split | Stratified `70/15/15` split with `random_seed=42` |
| Resize | All processed images are resized to `224x224` |
| Metadata | Includes source, original label, mapped label, Vietnam flag, URL placeholder, event name, hash, dimensions, and file sizes |

### Text branch

The notebook now prepares a secondary Vietnamese rescue-text dataset with:

| Requirement | Implementation |
|---|---|
| UIT-VSMEC base dataset | Download and remap into rescue-oriented labels |
| Rescue message samples | Expanded synthetic Vietnamese set for pipeline verification |
| Cleaning pipeline | Lowercasing, URL removal, phone masking, simple teencode normalization |
| Label schema | `urgent_rescue`, `need_supplies`, `safe_update`, `irrelevant` |
| Reports | Separate text dataset report and label schema markdown |

## 3. Demo Inference Scope

### Image models

The inference notebook benchmarks these pre-trained models without training:

| Model | Role |
|---|---|
| MobileNetV3-Small | Primary edge deployment candidate |
| MobileNetV3-Large | Larger mobile baseline |
| EfficientNet-Lite0 | Lightweight alternative |
| ResNet-18 | Heavier reference baseline |

For each model, the notebook prepares:

- Sample-image manifest based on `dataset/metadata.csv`
- Top-3 predictions per image
- GPU and CPU inference latency summaries
- Model size and parameter comparison tables
- CSV outputs saved under `dataset/reports/`

### Text models

The inference notebook also prepares demo runs for:

| Model | Role |
|---|---|
| PhoBERT-base | Vietnamese feature extraction and tokenization verification |
| XLM-RoBERTa XNLI | Zero-shot urgency classification baseline |

The text section records:

- Model loading time
- Vocabulary size when available
- Average inference time on demo rescue texts
- CSV outputs with predictions and timing under `dataset/reports/`
